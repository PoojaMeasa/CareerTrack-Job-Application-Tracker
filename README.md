# CareerTrack – Job Application Tracker

## About the Project

CareerTrack is a web application developed to help users manage and track their job applications in one place. Users can add job application details, view applications, update information, and track their application status.

The project uses React.js for the frontend, Spring Boot for the backend, and MySQL for database storage.

## Technologies Used

* **Frontend:** React.js, HTML, CSS, JavaScript
* **Backend:** Java, Spring Boot, Spring Data JPA, Hibernate
* **Database:** MySQL
* **Tools:** Eclipse IDE, Visual Studio Code, Maven, Git, GitHub

## Features

* User Registration and Login
* Add job application details
* View job applications
* Update application information
* Delete job applications
* Track application status
* Store application details in MySQL

## How to Run the Project

### Prerequisites

* Java JDK
* Node.js and npm
* MySQL Server
* Eclipse IDE or another Java IDE

### 1. Configure the Database

Create a MySQL database named `batch76` and configure the database connection in your local Spring Boot `application.properties` file.

**Important:** Do not upload database passwords or email credentials to GitHub.

### 2. Run the Backend

Open the backend project in Eclipse and run the Spring Boot application.

The backend is configured to use port `9999`.

### 3. Run the Frontend

Open a terminal in the project folder and run:

```bash
cd frontend
npm install
npm start
```

The React application normally opens at `http://localhost:3000`.
